# AI 智能导游 - MVP需求分析

## 一、项目定位

通过 AI 对话帮助用户从零生成定制化旅行方案，或对已有想法的用户给出优化建议，最终以对话或文档形式交付。

## 二、目标用户与核心场景

**目标用户**：任何想要量身定制旅游计划的人。



* **场景一：从零生成**。用户只有模糊意向（如 “想周末去周边散心”），AI 通过引导式提问明确需求，输出完整行程。

* **场景二：优化已有想法**。用户给出目的地、预算或行程草稿，AI 指出问题并给出更优建议。

## 三、核心流程



1. 用户在屏幕中间的对话输入框描述需求。

2. AI 判断信息是否充分，不足时围绕目的地、天数、预算、出行方式、偏好等维度追问。

3. 信息充分后，生成包含日程、交通、景点、餐饮、预算建议的结构化旅游计划。

4. 用户多轮提出修改，AI 基于会话上下文持续调整。

5. 用户确认后，以对话消息或文档形式交付最终计划。

## 四、MVP 界面要求（可验收）



* 整体风格简洁、专业、不单调，参照阿里云百炼平台的设计风格。

* 对话输入框位于屏幕中间并作为视觉焦点，页面加载后无需滚动即可看到并直接输入。

* 对话消息流围绕输入框展开，用户消息与 AI 回复区分清晰，可完整查看多轮历史记录。

* 输入框支持多行输入与发送；内容为空时发送按钮不可用，或给出明确提示。

* AI 回复期间展示明确的加载状态，避免用户重复发送。

* 桌面端与移动端均为响应式布局，移动端可单手操作，无横向滚动与内容错位。

## 五、MVP 范围

**做什么**

一句话总结：AI 能通过预设 Prompt + 多轮对话，给出合理且详细的旅行方案



* 对话式 Web 界面：居中输入框、消息流、基础响应式布局。

* 后端接入大模型对话能力，配置智能导游系统提示词。

* 基于内存的多轮会话上下文。

* 对话内输出结构化的旅游详细方案。

**不做什么**



* RAG 知识库与向量检索。

* ReAct Agent 与工具调用。

* 联网搜索。

* 数据库与持久化存储。

* 用户体系与付费权益。

* 微信小程序适配。

* 行程文档导出。

## 六、验收标准



* 给定典型旅游需求，用户可通过多轮对话获得包含日程、景点、预算建议的完整定制化旅游计划。

* 信息不足时 AI 主动追问，而非直接生成不完整方案。

* 多轮对话支持基于上下文连续追问与修改，无需重复描述背景。

* 生成的行程结构清晰、条目完整，在对话中可直接阅读。

* 桌面端与移动端主流浏览器下布局正常，无明显错位或横向滚动。

* 服务重启后会话清空属于本阶段预期行为，不作为缺陷处理。
